# Contributing

This repository hosts Meta's patches to Cuttlefish for macOS support. It
is a **publish-only** repository — we do not accept pull requests at this time.

If you'd like to contribute to Cuttlefish upstream, please see
https://source.android.com/docs/setup/contribute.

## Code of Conduct

This project has adopted a Code of Conduct that we expect participants to
adhere to. Please read [the full text](CODE_OF_CONDUCT.md) so that you can
understand what actions will and will not be tolerated.
